# What works

What Steep needs a server for, and how far ReSteep provides it. In short: sign-in, progression, the store, challenge
rewards, leaderboards, replays and ghosts, player-made challenges, cloud saves and multiplayer all work. The store
needs the optional [game-data pack](../hosting/game-data.md).

| | Meaning |
| --- | --- |
| ✅ | Works as it did with Ubisoft's servers |
| 🟡 | Works partly, or not verified everywhere |
| ⛔ | Not planned: not part of Steep's gameplay, or not worth emulating |

## Getting online

| Feature | | Notes |
| --- | --- | --- |
| Ubisoft Connect sign-in | ✅ | With your account on the server; Connect stays signed in |
| Game login (Steam and Ubisoft Connect versions) | ✅ | The final update (TU7) of both |
| Owned games and DLCs | ✅ | Steep and its add-ons; paid add-ons for their owners ([Your DLCs](../get-started/dlc.md)) |
| Several players on one server | ✅ | An account per player, each with their own progress |

## Progression and economy

| Feature | | Notes |
| --- | --- | --- |
| Level and XP per sport, playtime | ✅ | From the game's own uploads; never goes down |
| Medals, drop zones, memorables, unlocks | ✅ | |
| Store: buying items with credits | ✅ | Needs the game-data pack (the catalogue) |
| Challenge rewards (credits, items) | ✅ | From the game's own reward packs, no pack needed |
| Rider card and favourites | ✅ | |
| Personal best per challenge | ✅ | |
| Achievements | ✅ | Names and icons in Ubisoft Connect need the game-data pack |
| Taking over progress from Ubisoft's servers | 🟡 | Only from recordings of your own online sessions |

## Competing and sharing

| Feature | | Notes |
| --- | --- | --- |
| Leaderboards | ✅ | The server's players; weekly and daily boards too |
| Replays and ghosts | ✅ | Saved rides and photos are shared; ranked challenges have ghosts |
| Player-made challenges | ✅ | Kept with a leaderboard each; others download them from your profile |
| Seasons and tournaments | 🟡 | No season runs, as on Ubisoft's servers at the end |

## Playing with others

| Feature | | Notes |
| --- | --- | --- |
| Other riders in the world, groups | ✅ | Riders in the same area meet; groups with **G** or Join group; spectating |
| Matchmaking | ✅ | Players in the same world and area share a session |
| Friends list | 🟡 | Every other player on the server is a friend; invites and blocks are not available |
| Other players' profiles | ✅ | |
