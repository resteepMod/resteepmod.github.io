# The game-data pack

ReSteep runs without one: the server builds what the game and Ubisoft Connect need to go online. What it can't build
is Ubisoft's own game data:

- the **store catalogue** (2,000+ offers);
- the **achievement names and icons** Ubisoft Connect shows;
- **Ubisoft Connect's own pages** in its window and overlay;
- which items each DLC grants.

That data is not part of ReSteep. It comes as an optional **game-data pack**, a `.zip` built from recordings of your
own online sessions. Challenge rewards don't need it: they come from the game's own reward packs.

## Install a pack

{{< tabs >}}
{{% tab "Windows" %}}
Open a command prompt in the program's folder and run:

```
powder-server.exe -c "%LOCALAPPDATA%\ReSteep\config.toml" gamedata install steep-gamedata.zip
```
{{% /tab %}}
{{% tab "From the source code" %}}
```
target/release/powder-server gamedata install steep-gamedata.zip
```
{{% /tab %}}
{{< /tabs >}}

The server uses it from the next Play.

## Build a pack

```
powder-server gamedata build <recordings> gamedata    # allow-list and privacy check
powder-server gamedata verify                         # manifest and file hashes
powder-server gamedata zip steep-gamedata.zip         # the pack as one .zip
```

The builder copies only allow-listed, game-wide replies. It collects every identifying value from the recordings
(account and profile ids, names, email, tickets, friends, other players) and refuses to write the pack if any of them
appears in it. Everything personal is generated by the server instead.

## Packs from others

A pack may come from someone else, so the server trusts none of it. On install and on every start it applies the
builder's allow-lists again and refuses a pack that doesn't pass. A pack can't change which games Ubisoft Connect
starts.

> [!NOTE]
> Whether and how packs may be shared is still open: see [Rules and legal stance](../about/rules.md).
