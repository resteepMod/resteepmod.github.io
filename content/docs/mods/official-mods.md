# Official mods

The ReSteep team's mods live in [resteepMod/official-mods](https://github.com/resteepMod/official-mods). Install them
from the launcher's **Mods → Official** tab.

## On a server: who needs the mod?

Other players' games get your rider from your game directly (where you are, how you move), not from your mods.
What a mod draws, moves or plays on your PC stays on your PC. Some mods change what everyone shares, though, and must
then match between the server and every player.

| Mod | On a server |
| --- | --- |
| ReSteep Park, ReSteep Hill, ReSteep Mountains | **Must match.** New maps; the server runs one of the three (they share one world slot). |
| ReSteep Boxes, Lua Hat Demo | **Must match.** New items: the server runs it and every player needs it. |
| Challenge Example | **Must match.** Challenges and their leaderboards. Keep its settings at the defaults on a server. |
| Domino Playground, Domino Showcase, Example Script | **Must match.** Scripts placed in the maps; what they do happens to you only. |
| FPV Drone | **Must match.** It places the drone in the Alps. The others see your rider standing still while you fly. |
| Helicopter | Others see your rider floating through the air without the helicopter. |
| Physics Playground | Others see you jump, float or drop. Switch it off (**F11**) before a race. |
| Boost | Others see you race along the ground. Not for races. |
| Checkpoint Race | Only you need it. Times share a board with players who have the same course on the same server. |
| Air-time Contest | Only you need it. The longest air goes to the server's board. |
| Golden Hour | Local: the light and the clock change on your PC only. |
| Rider Colors, Example Animation | Local: your PC draws every rider with them. |
| Camera Effects, GoPro Stabilized, Speedometer, Markers, Crash Log, Event Notifications, Dev Tools, Hello Config | Local: on your screen only. |
| Frame Step | Single player only. |
| World Editor | The edits belong to the server: [The world editor](world-editor.md). |
| Butter | Only you need it; others see you ride as the game sends it. |

> [!NOTE]
> The server can't check what mods do on a player's PC: challenge times and the mods' boards take what the games
> send. Ride races without mods that move the rider or change the physics.
