# ReSteep documentation

ReSteep keeps Steep playable once you no longer want to, or can no longer, depend on Ubisoft's online services. It
is a server that answers the game in Ubisoft's place, a launcher that starts the game against it, an in-game menu,
and a modding system.

Where to begin:

- **New to ReSteep?** [Get started](get-started/) walks you through installing it on Windows or Linux and your first
  Play.
- **Playing:** [the launcher](play/launcher.md), [the in-game menu](play/in-game-menu.md),
  [playing with friends](play/multiplayer.md) and [your progress and saves](play/progress.md).
- **Mods:** [adding and managing mods](mods/), [the official mods](mods/official-mods.md) and
  [the world editor](mods/world-editor.md).
- **Making mods:** [the modding guide](modding/), from [your first mod](modding/first-mod.md) to
  [publishing it](modding/publishing.md).
- **Running a server for others:** [Hosting](hosting/).
- **Something went wrong?** [Troubleshooting](troubleshooting/).
