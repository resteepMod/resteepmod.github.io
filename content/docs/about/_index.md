# About ReSteep

ReSteep is an unofficial, community-run fan project. Its goal is a Steep that lives on, run by its players, with a
real, usable modding API.

- [Rules and legal stance](rules.md): what ReSteep is and isn't, and the rules for shared mods.
- [Credits and licence](credits.md): who made it, and under which licence.

## Contributing

ReSteep's code is on GitHub: [resteepMod/ReSteep](https://github.com/resteepMod/ReSteep). Bug reports are welcome as
[issues](https://github.com/resteepMod/ReSteep/issues) ([how to write one](../troubleshooting/logs.md)); security
problems go through [private reporting](../reference/security.md#reporting-a-vulnerability).

This website lives in [resteepMod/resteepmod.github.io](https://github.com/resteepMod/resteepmod.github.io): every
page has an **Edit this page** link at the bottom.
